# 循环集市 · 校园二手物品流转与闲置发布平台

大一课程实践（新手练手）项目：以校园二手闲置交易为场景，完整走一遍
**需求分析 → 方案设计 → 简单开发 → 测试优化 → 总结结题** 的项目全流程。

纯 HTML / CSS / 原生 JavaScript 实现，**零依赖、无需联网、无需部署**。

## 功能一览

- **首页物品展示**：Hero 横幅 + 商品卡片网格（价格贴纸 / 分类贴纸）
- **物品分类**：6 大校园分类一键筛选（教材教辅 / 数码电子 / 生活用品 / 运动户外 / 衣物包包 / 其他闲置）
- **搜索功能**：关键词实时匹配标题、描述与分类名，可与分类组合使用
- **物品详情**：大图、成色标签、物品描述、发布人卡片、浏览计数
- **个人发布入口**：表单校验 + 图片预览，发布保存到浏览器 localStorage，可在「我的发布」中删除

> 明确不做（按任务书要求）：实名认证、在线交易、聊天私信、后台审核、服务器部署。

## 快速开始

方式一（最简单）：双击 `index.html`，在浏览器中打开即可。

方式二（可选，本地小服务器）：

```bash
# 任选其一
npx serve .
npx http-server .
```

打开后即可体验：逛首页 → 点分类/搜索 → 看详情 → 发布闲置 → 管理我的发布。
所有「我的发布」数据仅保存在本机浏览器（localStorage），演示数据均为模拟。
