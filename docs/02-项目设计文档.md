# 校园二手物品流转与闲置发布平台 · 项目设计文档

> 项目代号：循环集市 ｜ 文档版本：v1.0 ｜ 对应任务书阶段：系统方案设计

## 一、技术方案

| 项 | 选型 | 说明 |
| --- | --- | --- |
| 页面结构 | HTML5（单页 `index.html`） | 三个视图共用一个页面，通过 hash 路由切换 |
| 样式 | CSS3（`styles.css`） | CSS 变量统一视觉体系，Grid/Flex 布局，响应式 |
| 逻辑 | 原生 JavaScript（`app.js`） | 无框架、无构建工具，新手可读 |
| 数据 | 模拟数据 + localStorage | 无后端、无数据库，满足任务书「本地可运行」要求 |
| 路由 | hash 路由 | `#/home`、`#/detail?id=1`、`#/publish`，刷新不迷路 |

**选型理由**：贴合大一知识储备（HTML/CSS/基础 JS），零环境搭建成本，重点放在流程学习而非技术攻关。

## 二、功能模块设计

```
循环集市
├── M1 首页物品展示 —— Hero 区 + 商品卡片网格 + 空态提示
├── M2 物品分类     —— 横向分类条（全部 + 6 分类），点击即时筛选
├── M3 搜索功能     —— 关键词实时匹配标题/描述/分类名
├── M4 物品详情     —— 大图 + 标签 + 描述 + 发布人卡片 + 浏览计数
└── M5 个人发布入口 —— 发布表单（校验/图片预览）+ 我的发布（删除）
```

模块间通过 `state = { keyword, category }` 单一状态驱动：搜索或切换分类只更新状态并重新渲染列表，逻辑简单、便于调试。

## 三、数据规划（替代专业数据库）

### 3.1 模拟数据（`data.js`）

- `CATEGORIES`：6 个分类，含 `id / 名称 / 主题色 / 默认图`。
- `MOCK_ITEMS`：10 件预设闲置物品，字段包含 `id、title、price、category、condition、desc、seller、dorm、time、views、img`。

### 3.2 用户数据（浏览器 localStorage）

- 存储键：`secondhand_user_items`
- 数据结构：与模拟物品同构的 JSON 数组，另加 `isMine: true` 标记与 `contact` 字段。
- 读取失败或数据异常时自动降级为空数组，保证页面不崩溃。

### 3.3 数据合并规则

展示列表 = 模拟数据（`MOCK_ITEMS`）+ 我的发布（localStorage），用户发布置顶显示。

## 四、页面结构与原型说明

单页三个视图（`.view`），同一时刻只显示一个：

| 视图 | 路由 | 布局说明（对应手绘原型） |
| --- | --- | --- |
| 首页 | `#/home` | 顶栏（logo + 发布按钮）→ Hero 横幅（标语 + 统计贴纸 + 搜索框）→ 横向分类条 → 商品卡片网格（2~5 列自适应）→ 页脚 |
| 详情 | `#/detail?id=x` | 返回按钮 → 左图右文两栏（移动端上下堆叠）：大图 + 价格贴纸 / 分类成色标签 + 标题 + 描述 + 发布人卡片 |
| 发布 | `#/publish` | 表单卡片（名称/分类/价格/成色/描述/联系人/宿舍/图片）+ 「我的发布」列表（缩略图 + 价格 + 删除按钮） |

移动端额外提供固定底部导航（首页 / 发布），宽度 ≤768px 时显示。

## 五、视觉设计

- **风格关键词**：校园纸感 × 循环环保。
- **色彩体系**：米白纸感基底 `#F7F2E6`、深青绿主色 `#1E6B4F`、贴纸黄强调 `#FFC93C`。
- **签名元素**：手写感「价格贴纸」（旋转 3° 描边阴影）、「分类贴纸」、Hero 处旋转的循环箭头圆环。
- **字体**：系统字体栈（ZCOOL / PingFang / Microsoft YaHei 逐级回退），不请求外部字体，保证离线可用。

## 七、关键设计决策记录

| 决策 | 原因 |
| --- | --- |
| 用 hash 路由而非三个独立 HTML | 保持单文件数据共享简单，刷新后详情页也能通过 URL 恢复 |
| 用户输入统一 HTML 转义 | 防止发布内容中的 `<script>` 破坏页面结构 |
| 图片超过 1MB 自动改用分类默认图 | 避免塞爆 localStorage，简化错误处理 |
| 删除前弹窗二次确认 | 防止误触，符合「基础体验完整」要求 |
